# FORMA — Digital-студия

Адаптивный одностраничный сайт вымышленной digital-студии для учебного задания по HTML, CSS и JavaScript.

## Запуск
Откройте `index.html` в браузере или запустите через расширение Live Server в Visual Studio Code. Для Google Fonts и Font Awesome требуется интернет.

## Структура
```
forma-studio/
├── index.html
├── README.md
├── css/style.css
├── js/main.js
└── img/
    ├── hero-architecture.svg
    ├── about-workspace.svg
    ├── service-device.svg
    └── case-interior.svg
```

## Изображения
- `hero-architecture.svg` — фон главного экрана.
- `about-workspace.svg` — иллюстрация блока «О нас».
- `service-device.svg` — иллюстрация блока «Услуги».
- `case-interior.svg` — иллюстрация блока «Кейсы».

## Что реализовано
- Разные шрифты и крупный заголовок с объёмной тенью.
- Hover-эффекты меню, кнопок и изображений.
- Скругления, плавные переходы и анимации.
- Шахматная композиция блоков на CSS Grid и Flexbox.
- Адаптивная мобильная версия и гамбургер-меню.
- Иконки Font Awesome 4.7.
- JavaScript для навигации, закрытия меню клавишей Escape и автоматического года в футере.

Ссылки на социальные сети демонстрационные — при необходимости замените их адресами своих профилей.
