# Тайны собак

Адаптивный одностраничный сайт о собаках. Учебная работа по HTML и CSS.

## Запуск
Откройте `index.html` в браузере или используйте Live Server в Visual Studio Code. Для Google Fonts, Font Awesome и фотографий требуется подключение к интернету.

## Структура
```
zadanie4/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── main.js
```

## Что реализовано
- Разные шрифты с поддержкой кириллицы.
- Объёмный заголовок с помощью `text-shadow`.
- Подсветка пунктов меню при наведении.
- Скругления углов, плавные переходы и масштабирование фотографий.
- Шахматная вёрстка двух основных информационных блоков на Flexbox.
- Пропорции изображений: логотип 2:1, главный баннер 3:1, изображения шахматки 1.5:1.
- Адаптивная мобильная версия с гамбургер-меню.
- Изменение размеров текста с помощью `clamp()` и относительных единиц.
- Иконки Font Awesome 4.7.
- JavaScript для мобильного меню и автоматического года в подвале.

Фотографии загружаются с Unsplash, шрифты — с Google Fonts, иконки — с CDN Font Awesome.
